# mindctx-mcp

Internal library for mindctx: `rmcp` stdio server + tool registry.

> **Do not depend on this directly.** The API is unstable and is only published to crates.io
> as a companion crate so `mindctx` can resolve its path dependency. No semver guarantees.
> Business logic must not live in the MCP handlers (transport coupling).

See the [mindctx](https://github.com/HouByte/mindctx) repository for the product.
