# mindctx-core

Internal library for mindctx: indexing / retrieval / encoding / knowledge base / packing.

> **Do not depend on this directly.** The API is unstable and is only published to crates.io
> as a companion crate so `mindctx-mcp` and `mindctx` can resolve their path dependencies.
> No semver guarantees.

See the [mindctx](https://github.com/HouByte/mindctx) repository for the product.
